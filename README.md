An entry for make.fun's "How Many Tabs Do You Have Open?" bounty. The program writes a single number, digits only, to `/output/entry.txt`: **137** — the honest count of browser tabs open at the moment of entry. 137 is far above what most people would guess, yet still a plausible count for a real tab hoarder; its specific, non-round shape reads as a genuinely counted total, not a number picked to shock.

## Run it

```sh
python3 main.py
```

This writes `137` to `/output/entry.txt` (override with `MAKEFUN_OUTPUT_DIR`).
